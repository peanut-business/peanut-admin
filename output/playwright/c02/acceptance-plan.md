# C02 文章业务验收记录

> 状态：已完成  
> 契约：`docs/likeadmin-article-contract.md`  
> 原则：验证业务需求和用户可见结果，不比较 UI、路由、接口形态或精确文案；C01 禁止重复验收

## 1. 验收范围

C02 的最低充分验收覆盖：

- 文章新增、详情、编辑、发布/隐藏和软删除；
- 标题、分类、状态筛选及列表核心信息；
- 公开列表、详情、浏览量和 PC 分类聚合；
- 收藏、取消、恢复及有效收藏统计；
- 普通管理员的菜单、动作授权、撤销和恢复；
- 文章、分类、用户、收藏关系之间的数据不变量；
- 双端临时数据精确清理。

不在本次范围内：

- 前端视觉、页面路由、接口路径、参数名和响应 envelope 一致；
- LikeAdmin 精确错误文案或内部实现形式；
- 为旧字段、旧参数或旧路由建立兼容层；
- 复制 LikeAdmin 的隐藏文章泄漏、无效文章可收藏等缺陷；
- M02 素材库。C02 仅要求正文图片和视频可直接上传插入。

## 2. 业务验收矩阵

| 能力 | 最低充分断言 | 结果 |
|---|---|---|
| 后台 CRUD | 文章可新增、回显、编辑、改状态和软删除，失败请求不写入 | 通过 |
| 列表查询 | 标题、分类、状态三个筛选有效，核心列表信息与业务排序正确 | 通过 |
| 状态消费 | 隐藏文章后台可管理，公开端与收藏列表不可见；恢复后重新可见 | 通过 |
| 浏览量 | 列表不增加实际浏览量，成功打开详情增加一次 | 通过 |
| 收藏 | 收藏/重复收藏/取消/重复取消/恢复保持幂等且无重复活动关系 | 通过 |
| PC 聚合 | 只展示启用分类及有效发布文章，分类停用后分类块消失 | 通过 |
| 权限 | 授权时入口和动作可用，撤权后入口不可用且服务端拒绝，恢复后可用 | 通过 |
| 软删除 | 文章退出全部活动消费端，收藏历史不级联删除 | 通过 |
| 正文媒体 | 图片和视频可以直接上传并插入正文 | 通过 |
| 清理 | 双端本次管理员、会员、会话、关系、日志、收藏及临时文件清零 | 通过 |

## 3. 状态消费结论

| 文章/分类状态 | 后台管理 | 移动列表与详情 | 有效收藏列表 | PC 资讯中心 |
|---|---|---|---|---|
| 文章发布、分类启用 | 可见 | 可见 | 已收藏时可见 | 分类和文章可见 |
| 文章隐藏、分类启用 | 可见 | 不可见 | 不可见 | 文章不可见 |
| 文章发布、分类停用 | 可见 | 可见 | 已收藏时可见 | 分类块不可见 |
| 文章软删除 | 不可见 | 不可见 | 不可见，历史关系保留 | 不可见 |

## 5. 有意差异

- Peanut 的 PC 资讯中心不泄漏隐藏文章。
- Peanut 不允许收藏无效、隐藏或软删除文章。
- Peanut 用户中心只统计有效收藏。
- Peanut 使用自己的 ThinkPHP 分层、前端框架、路由和接口协议。

这些差异不削弱 LikeAdmin 的产品能力，属于有意保持的正确业务规则，不计为待修复差异。
