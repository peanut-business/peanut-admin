> 参考：LikeAdmin 1.9.4  
> Peanut：当前工作区实现  
> 状态：已实现并完成最低充分验收  
> 口径：只对齐产品能力、实体关系、规则、权限、状态流、数据不变量和用户结果；不对齐 UI、路由、接口形式或字段命名。

## 1. 业务知识图谱

```text
管理员权限
  ├─ 管理素材分类
  ├─ 上传图片 / 视频 / 文件
  ├─ 查询、预览、复制地址
  ├─ 移动、重命名、批量删除
  └─ 在业务表单或编辑器中选择已有素材

素材类型 1 ── N 分类树 1 ── N 素材记录 1 ── 1 存储对象
  │                  │                    ├─ 本地
  │                  │                    └─ 当前云存储引擎
  │                  └─ 来源：后台上传 / 用户上传
  └─ 图片 / 视频 / 普通文件

业务表单或富文本编辑器 ── 素材选择器 ── 返回一个或多个素材 URL
```

核心实体：

| 实体 | 核心信息 | 约束 |
|---|---|---|
| 素材分类 | `id`、父分类、类型、名称 | 分类只管理同一素材类型；允许父子层级 |
| 素材记录 | 分类、类型、名称、相对 URI、来源、来源对象、时间 | URI 指向一个存储对象；列表 URL 由当前存储规则派生 |
| 存储对象 | 引擎、对象键/本地路径 | 上传成功后落库；删除素材同步删除存储对象 |
| 素材选择结果 | 类型、数量上限、URL | 单选/多选均可，不能超过调用方限制 |

## 2. LikeAdmin 1.9.4 能力

- 图片、视频、普通文件三类素材分开管理。
- 每种类型拥有独立分类树，可新增根分类和子分类、重命名及删除。
- 选择父分类时，列表包含该分类及全部后代分类的素材。
- 删除分类前明确提示；确认后删除分类子树及其中素材，并同步删除本地或云端存储对象。
- 素材列表支持名称模糊查询、上传来源筛选、分页和新记录优先。
- 上传进入当前选中分类，成功后产生素材记录并返回可访问 URL。
- 素材支持单个/批量删除、批量移动和重命名。
- 管理页支持预览和复制地址；列表/网格只是呈现方式，不是业务一致性门槛。
- 通用素材选择器支持类型限制、单选/多选、数量上限和返回 URL，被文章封面、富文本编辑器及后续配置/装修业务复用。

参考实现存在的不足不复制：目标分类、素材 ID 或跨类型关系校验不足；存储删除失败仍可能继续删库记录。Peanut 应保持相同用户能力，但补齐输入校验，并避免伪成功。

## 4. M02 实现要求

### 4.1 分类与列表

- 分类列表返回同类型的稳定树结构；支持根分类和子分类新增、重命名，名称限制为 20 个字符。
- 新增子分类时，父分类必须存在且类型一致。
- 选择父分类时，查询范围包含其全部后代；“全部”和“未分组”语义独立。
- 支持按素材类型、名称、上传来源和分类范围组合查询，按 `id desc` 分页。
- 删除分类使用明确确认；成功后分类子树、素材记录和对应存储对象均退出活动数据。
- 删除过程中任一存储操作失败时不得返回伪成功；数据库不得留下孤儿分类或孤儿素材。

### 4.2 素材动作

- 上传类型、扩展名、大小和目标分类必须有效；目标分类必须与上传类型一致。
- 移动支持单个或批量素材；目标为未分组或同类型有效分类。
- 重命名名称必填并限制为 20 个字符；不存在的素材不得返回成功。
- 删除支持单个和批量，成功后软删除记录并删除存储对象。
- 空 ID 集合、无效 ID、跨类型目标和无效分类不得静默成功。

### 4.3 选择与消费

- 提供 Peanut 自有通用素材选择器，支持图片/视频/文件、单选/多选和数量上限。
- 选择器复用素材查询和上传能力，返回业务组件可直接保存的 URL，不建立 LikeAdmin 路由或参数兼容层。
- 文章封面可选择已有图片；富文本编辑器可选择已有图片/视频插入正文，同时保留直接上传能力。
- 后续渠道、装修和系统设置复用同一选择器，不为每个模块建立重复素材链路。

### 4.4 权限与不变量

- 普通角色按素材查看/上传、分类管理、移动、重命名、删除动作授权。
- 撤权后菜单或动作入口不可用，服务端直接请求被拒绝，业务数据不变化。
- 分类类型、素材类型和目标分类始终一致。
- 活动素材记录必须对应一个可定位的存储对象；删除成功后两者同时退出活动状态。
- 查询、预览、复制和权限拒绝不修改素材或分类。
