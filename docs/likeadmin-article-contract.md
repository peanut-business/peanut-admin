# C02 文章业务契约

> 参考：LikeAdmin 1.9.4 文章业务  
> 状态：已验收  
> 边界：只覆盖文章管理、公开阅读和收藏；文章分类 C01 已完成，禁止重复验收

## 1. 复刻口径

C02 复刻的是业务需求、业务能力、实体关系、规则、权限语义、状态流转和用户可见结果。Peanut 保持自己的 ThinkPHP 分层、字段命名、路由、接口协议和前端框架。

以下内容不属于一致性门槛：

- UI 布局、控件样式和页面路由；
- 接口路径、请求参数名、响应 envelope 和精确错误文案；
- LikeAdmin 内部类名、方法名和代码组织方式；
- LikeAdmin 的已知缺陷。

不得为了形式相似增加双字段、双路由、参数别名或其他兼容层。

## 2. 业务知识图谱

```text
文章分类
  1 ---- n 文章
             |
             | 被用户收藏
             v
用户 1 ---- n 收藏关系 n ---- 1 文章

管理员角色 ---- 授权 ---- 文章管理能力
                           |-- 查看列表/详情
                           |-- 新增/编辑
                           |-- 发布/隐藏
                           `-- 删除

文章状态 ---- 消费 ---- 后台列表 / 移动端 / PC 资讯中心 / 用户收藏
```

核心实体与关系：

| 实体 | 关键业务信息 | 关系与约束 |
|---|---|---|
| 文章 | 分类、标题、简介、摘要、封面、作者、正文、排序、虚拟/实际浏览量、发布状态、删除状态 | 归属一个有效分类；软删除后退出所有消费端 |
| 分类 | 名称、排序、启停和删除状态 | 一个分类包含多篇文章；分类状态影响 PC 分类块，不改变文章自身发布状态 |
| 收藏关系 | 用户、文章、收藏状态和时间 | 同一用户对同一文章按状态复用，不因文章删除而级联物理删除 |
| 管理员角色 | 文章菜单和动作能力 | 每个管理动作独立授权；撤权不改变业务数据 |

## 3. Peanut 数据映射

Peanut 使用一套单一文章模型：

| 业务概念 | Peanut 字段/关系 |
|---|---|
| 所属分类 | `cid` |
| 简介、摘要 | `desc`、`abstract` |
| 虚拟、实际浏览量 | `click_virtual`、`click_actual` |
| 发布状态 | `is_show` |
| 软删除 | `delete_time` |
| 收藏状态 | 用户、文章及状态组成的收藏关系 |

浏览量对外展示为虚拟浏览量与实际浏览量之和。后台编辑不能覆盖实际浏览量；封面及正文媒体按 Peanut 文件服务规则保存和解析。

该映射已经形成单一数据模型，不保留 LikeAdmin 历史字段或请求别名。

## 4. 管理端能力

### 4.1 列表与查询

管理员能够分页查看文章，并按标题、分类和发布状态筛选。列表展示足以识别和管理文章的核心信息，包括标题、分类、状态、排序和浏览量。

业务规则：

- 默认按业务排序值降序，同排序时按新记录优先；
- 隐藏文章仍出现在后台，便于恢复；
- 软删除文章不再出现；
- 状态值 `0` 是有效筛选条件；
- 文章列表不提供导出业务能力。

### 4.2 新增、详情和编辑

管理员能够选择有效分类，填写标题、简介、摘要、封面、作者、正文、排序、虚拟浏览量和发布状态，随后查看详情并继续编辑。

业务规则：

- 标题、分类和发布状态等必要信息必须有效；
- 无效输入不得新增或改变文章；
- 编辑保留文章的创建时间、实际浏览量和已有收藏关系；
- 正文支持图片和视频直接上传并插入编辑器；
- 素材分类、素材选择和素材删除属于 M02，不在 C02 提前实现。

### 4.3 状态与删除

```text
隐藏 --发布--> 发布 --隐藏--> 隐藏
活动文章 --删除--> 软删除文章
```

- 发布/隐藏只改变文章可见状态及框架维护的更新时间；
- 软删除只结束文章的活动生命周期，不级联删除分类、用户或收藏历史；
- 删除后后台活动列表、公开列表、详情、收藏列表和 PC 聚合均不可见。

## 5. 消费端能力

### 5.1 公开文章

访客和用户能够浏览已发布、未软删除的文章列表和详情，并按分类、关键词及默认/最新/热门语义查询。

- 默认排序遵循业务排序值，最新按新记录优先，热门按总浏览量优先；
- 列表读取不增加实际浏览量；
- 成功打开详情时实际浏览量增加一次；
- 隐藏、软删除或不存在的文章不能被公开读取；
- 分类停用不改变移动端文章自身的可读性。

### 5.2 收藏状态流

```text
未收藏 --收藏--> 已收藏 --取消--> 已取消
已取消 --再次收藏--> 已收藏
```

- 收藏和取消操作保持幂等；
- 再次收藏复用已有关系，不产生重复活动收藏；
- 只有已发布且未软删除的文章可以新增收藏；
- 文章下架后仍允许用户取消既有收藏；
- 收藏列表只统计并展示仍然有效、可公开阅读的文章；
- 用户中心的收藏数量采用相同有效收藏口径。

### 5.3 PC 资讯中心

PC 资讯中心按启用分类组织文章：

- 分类按业务排序展示；
- 每个分类展示有限数量的已发布、未软删除文章；
- 分类停用后整个分类块消失；
- 文章隐藏或软删除后只移除对应文章，不泄漏到聚合结果；
- 文章详情提供正文、浏览量以及相邻/同类内容等阅读能力。

## 6. 权限语义

文章管理能力由普通管理员角色独立授权。列表/详情、新增、编辑、状态修改和删除的入口与服务端动作应保持同一授权结果。

- 获得能力后可以看到入口并完成对应动作；
- 撤销某个动作权限后，该入口不可用且服务端拒绝直接调用；
- 其他已授权动作不受影响；
- 恢复权限后原动作重新可用；
- 权限拒绝不得改变文章、分类、收藏或浏览量数据。

Peanut 可以采用自己的菜单树、按钮粒度、页面形态和权限标识，只需保持上述能力边界和结果。

## 7. 业务不变量

1. 失败校验不新增、不编辑、不改状态、不删除文章。
2. 后台编辑不改变实际浏览量、创建时间和收藏关系。
3. 状态修改只改变发布状态及更新时间。
4. 详情成功读取一次，实际浏览量精确增加一次；列表读取不增加。
5. 同一用户与文章不存在重复活动收藏。
6. 软删除文章不再被任何活动列表或公开入口消费，收藏历史仍保留。
7. 分类停用只移除 PC 分类块，不改变移动端已发布文章的可读性。
8. 权限撤销和恢复不改变业务数据。

## 8. 有意不复制的参考缺陷

以下差异是产品规则修正，不是待复刻项：

- LikeAdmin PC 聚合可能泄漏隐藏文章；Peanut 始终过滤隐藏和软删除文章。
- LikeAdmin 某些路径允许收藏无效或下架文章；Peanut 只允许收藏有效、已发布文章。
- 用户中心只统计仍然有效的收藏，不把失效或下架文章计入数量。
