# 许可证与第三方告知

Peanut Admin 当前源码自开源许可变更提交起采用 Apache-2.0，版权主体显示为“花生科技”。Composer `peanut-admin/core` 与 npm `@peanut-admin/admin` 核心包同样采用 Apache-2.0。既有不可变 tag 与 GitHub Release 仍保留其发布时附带的许可证；这次变更不改写历史制品。
