# 能力边界

Peanut Admin 提供管理端、Platform 控制面、PC、H5/UniApp、原生管理身份、Tenant/RBAC、Module Runtime、安装升级与部署脚本。具体能力是否已发布、部署或仍在计划中，必须以对应 Release 和维护仓事实为准；本页不复制内部状态矩阵。

开发扩展从[核心概念](/guide/concepts)和[开发总览](/guide/development)开始。公开包与 API 入口见[参考资料](/reference)。
